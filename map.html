How to read this map

  • BASELINE pins show real 2023 CDC surveillance data: reported Lyme cases (confirmed + probable) per county. Source: CDC NNDSS county-level public-use data, public domain · full sources & caveats
  • COMMUNITY pins show expert-confirmed submissions to this project (sample demo data).
  • VERIFIED pins show real expert-confirmed submissions, county-aggregated. Appears once the upload pipeline is live and submissions are reviewed.
  • The time slider accumulates sample community reports through the selected month. Species filter isolates one vector.
  • A county with no pins means no data, not no risk. That's the point — send a photo.
This is not medical advice. The baseline layer is surveillance context (reported case counts, not personal risk); community pins are sample demo data. If you were bitten, see a clinician. CDC tick info · Michigan DHHS
