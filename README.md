# TickSignal

**Snap a photo of a tick or mosquito. Get a species ID in seconds. Watch the risk map — and the AI's accuracy — improve in public every week.**

TickSignal is an open, AI-powered tick & mosquito identification and risk-mapping research project run by Dakota McCall (Hastings, Michigan).

🌐 **Live pilot site:** https://dakotamccall200-create.github.io/ticksignal/
♥ **Support the project:** https://ko-fi.com/dakotamccall9

## What it does

- **Photo ID** — upload a phone photo of a tick or mosquito; the AI suggests the species in seconds, and a human expert confirms the tricky calls.
- **Public risk map** — every confirmed sighting joins an open Michigan county risk map.
- **Public accuracy dashboard** — we publish the AI's accuracy numbers, misses included. Latest independent test: **69.6% top-1 / 89.3% top-3 accuracy** on 56 real research-grade iNaturalist photos across 7 species (test write-up in the project notes).

## The deal

- **All core data is free forever.** Every ID, every map, every accuracy number — no account, no paywall, ever.
- Donations fund *speed and running costs* (training compute, alert texts, expert reviewer stipends) — never access, never results.
